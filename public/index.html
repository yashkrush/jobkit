How this works — and what costs anything

Fetching job boards is free. There are two ways in:

Search — look for specific titles right now, across everything currently posted, ignoring your saved filters.

Check what's new — uses your saved filters and shows only postings you haven't seen before.

The only paid step is pressing Grade on a role, which runs the real APPLY / MAYBE / SKIP analysis. Nothing grades itself unless you tell it to.

Filters & cost controls
What these four settings actually do

Auto-grade per run = 0 means nothing is ever graded without you pressing Grade. That's the recommended setting — everything stays free, and you spend one Claude call at a time on roles you picked. Raise it only if you'd rather wake up to verdicts already done.

The scheduled run is off by default. A sleeping laptop skips it anyway, so Check what's new is the reliable way to run it.

A region on the right vetoes a posting unless a region on the left is also named — "Remote, US" is dropped, "Remote, US; Remote, Germany" is kept. Plain "Remote", "Anywhere" and "Distributed" always survive.

Sources — job boards being scanned

Public, key-free ATS endpoints. The slug is the company's name in its careers URL — test before saving, so a typo doesn't turn into silence. Bulk-validate a list of names with node tools/discover-sources.js.
